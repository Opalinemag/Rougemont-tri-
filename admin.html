Être prévenu par mail

  1. Créez un compte gratuit sur resend.com avec l'adresse du club ().
  2. Dans Resend, menu API Keys → Create API Key, puis copiez la clé (elle commence par « re_ »).
  3. Collez-la ci-dessous, cliquez sur « Enregistrer », puis sur « Envoyer un mail d'essai ».
